DAY4TASK- The code contains two user input of SPDT switches and the leds(green and red) are glowing whenever the switches are turned on or off according to the question.
DAY5iTASK- The code blinks a specific colour of an led with, with respect to the object close to the ultrasonic sensor.
DAY5iiTASK- The code acts as a traffic light sensor and blinks a specific colour of an led to determine and conclude that the bot is at a safe distance.
DAY6iTASK- The code helps to blink an led when the object of an ultrasonic sensor is at a specific distance from it.
DAY7TASK- The code helps to rotate a dc motor at 50% duty cycle.
